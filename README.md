## A glowing world of possibilities

**Pixel World Map** is a customizable animated geographic background for Framer. A low-resolution world map comes alive through glowing activity pings, expanding square ripples, and smooth horizontal motion. Explore regions, focus on cities, or create a custom geographic view—all from Framer's properties panel.

No map API, external assets, or data subscriptions required. **Activity is simulated, not real-time analytics or actual network traffic.**

## ✨ Features

| Feature | Experience |
| --- | --- |
| 🌍 **9 geographic views** | World, North America, South America, Europe, Africa, Asia, Middle East, Oceania, Custom |

| ✨ **Activity pings** | Animated glowing pixels with controllable density and lifetime |
| ◻️ **Square ripples** | Adjustable ripple visibility, size, and opacity |
| ↔️ **Scrolling** | Auto-scrolling map with adjustable speed, pause, and region locking |

| ⚡ **Performance** | Canvas rendering, DPR/area limits, offscreen and tab visibility pauses |
| ♿ **Accessibility-aware** | Reduced-motion and static SVG rendering paths |
| 📐 **Responsive** | Framer sizing support for flexible page layouts |

## 🚀 Use it in Framer

1. Open your project in [Framer](https://www.framer.com/).
2. Create a new code component named `KarimSaifPixelWorldMap.tsx`.
3. Paste the source from [`KarimSaifPixelWorldMap.tsx`](./KarimSaifPixelWorldMap.tsx).
4. Place the component onto the Framer canvas.
5. Customize the region, position, colors, activity, and animation from the Properties panel.
6. Preview and test your site across desktop and mobile, then publish.

**Recommended starting look:** World · Ember · Scrolling On · Activity 0.07.

## 🧩 Under the hood

- Single-file **React + TypeScript** Framer code component.
- **Canvas 2D** animated rendering, with an **SVG static renderer**.
- Reduced-motion support, animation frame cleanup, and visibility-aware animation handling.
- Stylized pixel geography, designed for visual storytelling rather than geographic accuracy.
